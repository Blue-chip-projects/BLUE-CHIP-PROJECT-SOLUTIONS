Model-linked planning for construction teams

A component can involve several stages: installation, inspection, testing and handover. Linking those activities to the same object helps the team discuss what is planned, what is committed and what is complete without losing the location of the work.

Find the work

Navigate the model and select individual mesh objects to identify the component being discussed.

Link the plan

Connect selected objects to existing schedule activities and inspect their linked work.

Review status in context

Use visual status to discuss planned, committed and completed work. An object becomes complete only when all its linked activity stages are complete.

Prepare the sequence

Use standard processes to prepare a planning draft, then review its dates, teams, constraints and milestone connections.

Using a model exported from Navisworks

The supported import route is an FBX export from Navisworks with individual objects preserved. Choose the correct source units and check the imported result before linking work. Large projects can be divided into building, floor or discipline exports.

Native NWD, NWC, NWF and IFC files are not read directly. FBX exports may not retain all original BIM properties or persistent object identifiers, so a revised model needs a matching review. This is a model-linked planning workspace, not a clash-detection or model-authoring tool.

ILLUSTRATIVE PROJECT SCENARIO

Example: coordinate installation and testing in a plant room

  1. Import a plant-room FBX export and identify the equipment to be installed.
  2. Link the equipment to its installation, inspection and testing activities.
  3. Review the committed work with the responsible trade and check the area and predecessor constraints.
  4. Update the linked activities as work is completed; review any outstanding stage before treating the component as finished.

Decision to make: Which component is ready for the next trade, and which still has unfinished linked work?

Questions from project teams

Can Jenasaro connect a construction schedule to a 3D model?

Yes. Selected model objects can be linked to schedule activities so their work and completion can be reviewed in physical context.

Does it open native Navisworks or IFC files?

No. The current route uses an FBX export from Navisworks. Native NWD, NWC, NWF and IFC reading is not supported.

Is this a full 4D simulation or BIM-authoring package?

Jenasaro focuses on linking construction activities, commitments and completion to model objects. Discuss any time-based animation, authoring or coordination requirement during the demo; do not assume every capability of a dedicated 4D simulation package.

Does completing one daily quantity turn an entire component green?

No. Component completion depends on the completion of all its linked activity stages, rather than one daily quantity entry.
